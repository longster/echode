# Echode

**Establishing Connections.**

Echode is the umbrella front door for Texas Deaf communities, city by city. Each city keeps its own local home, run the local way. Echode is the map that points to all of them.

The first city is Houston: [HoustonDeafNetwork.com](https://houstondeafnetwork.com) is live and unchanged, and echode.com/htx will point to it once the domain is wired to this site.

## Cities

| Code | City | Status |
| --- | --- | --- |
| HTX | Houston | Live (HoustonDeafNetwork) |
| ATX | Austin | Exploring |
| DFW | Dallas - Fort Worth | Exploring |
| SAT | San Antonio | Exploring |

A city opens when it earns it: local listings show up and events keep happening. Growth is submissions driven, and the community side stays free. Only businesses pay for visibility, and paid placements are labeled.

## This site

- A single hand-written `index.html` (HTML, CSS, and inline SVG). No framework, no build step.
- Current status: **homepage layout preview v1**, published on GitHub Pages at [longster.github.io/echode](https://longster.github.io/echode/). It is not the live echode.com site yet.
- The suggest form on the page is a design mock. Nothing sends yet; the live version will use a review queue, the same pattern as HoustonDeafNetwork's Get Listed intake.
- The logo is on hold. The header uses a plain text wordmark for now.

## Updating

Edit `index.html` and push to `main`. GitHub Pages republishes automatically within a minute or two.
